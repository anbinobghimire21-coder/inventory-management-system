# Inventory Management System

A full-stack Inventory Management System developed for Web Development coursework.

## Technology Stack

- React
- Vite
- Node.js
- Express.js
- SQLite
- Sequelize ORM
- JWT Authentication

## Core Features

- Admin login and authentication
- Product CRUD
- Supplier CRUD
- Product image upload
- Product search
- Supplier filtering
- Low-stock alerts
- Client-side validation
- Server-side validation
- Responsive design

## Project Structure

- `client/` - React frontend
- `server/` - Express REST API and SQLite database
